How to play with a friend
  1. Host: type your name → Create a room. You get a 5-letter code.
  2. Send the code (or the invite link) to your friends.
  3. Friends: open this game, type a name and the code → Join room.
  4. When everyone is in, the host taps Start game.

The host's device runs the game — the host must keep this page open.
